Cross-Dataset Evaluation Results — Chapman -> PTB-XL
======================================================
Date: 2026-06-01
Model: ECG_1DCNN Pruned (channels 4,4,8,8), QAT-INT8 power-of-2
Source dataset: Chapman (train/val/test, patient-independent split 70/15/15)
Target dataset: PTB-XL (patient-independent split 70/15/15)
  - 19,952 records usable (rhythm-label mappable)
  - Test set: 2,997 samples
  - Class distribution (test): SR~83%, AFIB~8%, GSVT~5%, SB~4%

Label mapping PTB-XL SCP -> 4-class:
  AFIB(0): AFIB, AFLT
  GSVT(1): STACH, SVTAC, PSVT, SVARR
  SB  (2): SBRAD
  SR  (3): SR

Preprocessing pipeline (matches Chapman):
  - 500 Hz -> 250 Hz downsample (scipy.signal.resample)
  - Lead II (channel index 1 in PTB-XL wfdb records)
  - Z-score normalize per record
  - Window: 10s = 2500 samples

======================================================
KEY FINDINGS
======================================================

1. Quantization drop = 0%
   C2 (QAT-INT8) == C6 (float32): acc=0.7714, f1=0.6486 identical.
   All 17% accuracy drop (C1->C2) is pure distribution shift, not quantization.
   Strong evidence for power-of-2 QAT methodology (paper contribution C1).

2. Feature transfer quality
   C3 linear probe (92.49%) ≈ C5 from scratch (92.79%) — gap only 0.3%.
   Conv layers learn transferable ECG features with only FC retraining needed.

3. SB/SR confusion is a clinical boundary problem
   Zero-shot: 453 SR samples misclassified as SB -> SB precision = 18%.
   Root cause: SB vs SR defined by HR threshold (60 bpm), not waveform morphology.
   CNN without explicit HR input cannot distinguish reliably.
   Even from-scratch training gives F1_SB = 0.670 (class still hardest).

4. Pruning does not hurt transfer (Ablation A5)
   Unpruned (1244 params): acc=0.7721, f1=0.6393
   Pruned   ( 654 params): acc=0.7714, f1=0.6486
   Pruned F1-macro is slightly HIGHER (+0.009) despite 47% fewer parameters.
   Pruning reduces params by 47% with no transfer ability degradation.

5. AFIB and GSVT generalize well
   AFIB F1 = 0.754 zero-shot (AF morphology: irregular RR, absent P-wave is distinctive).
   Recovers to 0.805 after full fine-tune.

======================================================
CLASS BALANCING EXPERIMENTS (C3/C4/C5 only)
======================================================

Motivation: PTB-XL train set heavily imbalanced (SR=83%, AFIB=8%, GSVT=5%, SB=3%).
Tested 3 balancing strategies to see if minority class F1 improves.

Train set sizes:
  Full (unweighted):       AFIB:1113  GSVT:709  SB:433  SR:11700  total=13955
  Undersample SR 3x:       AFIB:1113  GSVT:709  SB:433  SR:3339   total=5594
  Undersample SR 1x (bal): AFIB:1113  GSVT:709  SB:433  SR:1113   total=3368

Results — Accuracy / F1-macro:

Strategy              C3 linear probe    C4 full finetune   C5 from scratch
-----------------------------------------------------------------------------
Unweighted (full)     0.9249 / 0.7695    0.9329 / 0.7915    0.9279 / 0.7815
Weighted loss         0.8509 / 0.6986    0.8712 / 0.7182    0.8809 / 0.7166
Undersample SR 3x     0.9036 / 0.7498    0.9216 / 0.7823    0.8952 / 0.7321
Undersample SR 1x     0.8572 / 0.6970    0.8682 / 0.7135    0.8699 / 0.6987

CONCLUSION: Unweighted full dataset wins on both acc and F1-macro across all modes.
All balancing strategies hurt performance — trend: more aggressive balancing = worse results.

ROOT CAUSE: SB/SR confusion is a clinical boundary problem (HR threshold 60 bpm),
not a sampling bias problem. Reducing SR samples or penalizing SR loss does not
help model distinguish SB from SR — it only reduces total training data and
degrades generalization on the SR-dominated test set.

DECISION: Use unweighted full dataset as official results for paper.
Balancing experiments documented here as evidence that standard remedies
do not apply — supports the argument that SB/SR ambiguity is inherent.
