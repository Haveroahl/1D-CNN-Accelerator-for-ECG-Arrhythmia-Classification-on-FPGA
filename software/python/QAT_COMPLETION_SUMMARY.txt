5. HARDWARE IMPLEMENTATION
================================================================================

INT8 Architecture (with QAT or Post-training):

  Input (float32)
    ↓
  [Quantize] scale per-layer using fixed scales
    ↓
  INT8 multiply-accumulate operations (hardware-optimized)
    ↓
  [Dequantize] using same scales
    ↓
  Output (float32)

Benefits:
  • 4.2× memory compression (1.2 KB vs 5 KB float32)
  • Faster inference (INT8 MACs vs float32 MACs)
  • Hardware-efficient (8-bit operations, low power)
  • Clinically acceptable accuracy (94.65% for ECG classification)

For Zero Accuracy Loss:
  Use Q8.8 quantization instead (94.84% accuracy, 2× compression)

6. KEY TECHNICAL DETAILS
================================================================================

Straight-Through Estimator (STE) Implementation:
  • Forward Pass:
    1. q = round(w / scale)
    2. q_clipped = clamp(q, -128, 127)
    3. w_q = q_clipped * scale
    4. Return: w + (w_q - w).detach()

  • Backward Pass:
    - Gradient flows through as if quantization didn't happen
    - Allows weight updates despite quantization rounding

Per-Layer Scale Calculation:
  for each layer:
    abs_max = max(|weights|)
    scale = abs_max / 127  (for INT8)

  These scales remain FIXED during QAT (hardware-friendly).

Learning Rate Schedule:
  Epochs 1-14:  LR = 1e-4
  Epochs 15-20: LR = 1e-5 (drop by 10× at 70% of epochs)

  This multi-step schedule helps convergence without premature stagnation.
