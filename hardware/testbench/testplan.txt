0. ĐỐI TƯỢNG KIỂM TRA (RTL Modules Under Test)
--------------------------------------------------------------------------------
  M1  cp_block.v        — Conv-pool block 1 kênh: pipeline S1..S9
                          (MULT → adder tree → ACC → +bias → rescale shift +
                           round-half-up → clamp[-127,127] → ReLU → MaxPool K=5).
  M2  cp_engine.v       — 8× cp_block song song + SRW (shift-register window) +
                          weight/bias store ($readmemh) + delay chain a_d5/ce_d5 +
                          pad logic (front/back) cho Conv1.
  M3  cnn_controller.v  — FSM: IDLE→LOAD→CONV1→CONV2→CONV3→CONV4→GAP_FC→DONE,
                          phát nb/relu_en/in_len/cp_en per-layer, prefetch, bank_sel.
  M4  gap_fc_argmax.v   — GAP (floor sum/4) → FC(8→4, nb=0) → Argmax → result[1:0].
  M5  ping_pong_sram.v  — Dual-bank inter-layer SRAM 8 kênh, bank_sel toggle.
  M6  input_sram.v      — Input ECG 2500×8b, HPS write / CP read.
  M7  ecg_accelerator_top.v — Wire toàn bộ M1..M6 + avalon_slave.
  M8  avalon_slave.v    — Avalon-MM, các register control/status/result.

2. TESTBENCH 1 — tb_cp_block.v   (UNIT, .do: run_tb_cp_block.do)
--------------------------------------------------------------------------------
  VERIFY: toàn bộ pipeline 1 cp_block (M1) ở mức nhánh logic, drive trực tiếp
          a_in/compute_en_in/taps/w/bias (bỏ qua cp_engine delay chain).
  LƯU Ý KỸ THUẬT: pool S9 đếm pixel khi (relu_v && compute_en_in); relu_v trễ 9
          stage. Driver drive đủ pixel rồi DRAIN (compute_en_in=1, a_in parked ≠
          in_ch-1 → không sinh out_valid mới) để pixel cuối được pool. pool_write
          (xung 1-cy) được latch (pw_seen/pw_value/pw_count) cho check đọc.

  Test case (22):
    TC01a Zero pipeline (taps=0,bias=0,nb=0)          → pool_out=0  [reset/zero path]
    TC01b Basic pipeline (taps≠0, nb=8, bias=0)       → pool_out=0  [MULT+tree]
    TC02a Round-half-up nb=8, bias=128                → 1  [(128+128)>>8] LÀM TRÒN LÊN
    TC02b Round-half-up nb=8, bias=127                → 0  [biên không làm tròn]
    TC03  Clamp upper (nb=0, bias=200)                → 127  [bão hòa dương]
    TC04  Clamp lower (nb=0, bias=-200)               → -127 [bão hòa âm]
    TC05  Clamp exact upper (bias=127)                → 127  [biên trên đúng]
    TC06  Clamp exact lower (bias=-127)               → -127 [biên dưới đúng]
    TC07  ReLU on + âm (relu_en=1, bias=-50)          → 0    [ReLU cắt âm]
    TC08  ReLU on + dương (relu_en=1, bias=50)        → 50   [ReLU giữ dương]
    TC09  ReLU off + âm (relu_en=0, bias=-50)         → -50  [Conv1-3 giữ âm]
    TC10  MaxPool — max ở pixel đầu [100,50,30,20,10] → 100  [pool đầu window]
    TC11  MaxPool — max ở pixel cuối [10,20,30,50,100]→ 100  [pool cuối window]
    TC12  pool_write fire đúng 1 lần cho 5 pixel      → count=1 [chu kỳ pool K=5]
    TC13a Window 1 (5 pixel = 20)                     → 20   [2 window liên tiếp]
    TC13b Window 2 (5 pixel = 5)                      → 5    [pool_cnt reset đúng]
    TC14  IN_CH=4 accumulate (acc 4 kênh)             → 40   [ACC nhiều kênh]
    TC15  IN_CH=8 accumulate (acc 8 kênh = Conv4)     → 80   [ACC max-channel]
    TC16  NOP (compute_en_in=0) → không pool_write    → cnt=0 [gating compute_en]
    TC17  pool_rst giữa window → pool_cnt reset        → fire sau 5 fresh + val=33
    TC18  rst clears pipeline → không pool_write rác   → [reset toàn cục]

  COVERAGE đóng góp: round-half-up (lên/không lên), clamp 2 biên, ReLU on/off×dấu,
    pool max ở mọi vị trí, pool reset, multi-channel ACC (1/4/8), NOP/reset.
    → Đây là TB phủ NHÁNH datapath cao nhất (các case khó kích bằng dữ liệu thật).

    vsim -c -do cov_tb_cp_block.do     # -> cov_cp_block.ucdb

    vsim -c -do cov_merge_report.do    # DU-merge + exclude -> báo cáo functional
  (Compile +cover=bcefsx; vsim -coverage -onfinish stop để coverage save chạy
   sau $finish. tb_top_probe loại khỏi đo: trùng path tb_top, không thêm bin.)

  ── Hai kỹ thuật trong cov_merge_report.do để con số phản ánh ĐÚNG ──────────
  (A) DU-MERGE (vcover merge -du <module>...): mỗi TB instantiate design dưới top
      khác nhau (/tb_top/u_top, /tb_fsm/u_top, /tb_cp_block/dut). Merge thường
      giữ INSTANCE riêng → 1 nhánh chỉ phủ ở tb_fsm (vd DONE_S→LOAD re-start) bị
      tính "miss" dưới tb_top. Merge -du GỘP mọi instance của 1 module thành MỘT
      con số = độ phủ thật của module.
  (B) EXCLUDE unreachable defaults (cov_exclude.do, reason=EUR): loại các nhánh
      default / case-without-default "all-false" KHÔNG THỂ chạy với input hợp lệ
      (biến state/address luôn trong tập định nghĩa). Chỉ fault-injection (ép
      state lạ) mới chạm — không phải functional. Danh sách loại (6 dòng):
        cnn_controller L239,273 (default case CONV/GAP_FC), L288 (illegal-state)
        gap_fc_argmax  L106 (GAP default), L191 (argmax_step all-false)
        avalon_slave   L46  (write case all-false: địa chỉ ghi không decode)
  Toggle bị BỎ khỏi functional (-code bcefs): ~4K+ toggle bin là bus weight/acc/
  datapath — hằng hoặc phụ thuộc dữ liệu; GIÁ TRỊ đã chứng minh BIT-EXACT bởi
  tb_top (bằng chứng đúng thật sự), nên toggle là nhiễu, không phản ánh functional.
