0. ĐỊNH VỊ ĐỀ TÀI (quan trọng nhất — đọc trước)
--------------------------------------------------------------------------------
- Đề tài = THIẾT KẾ + KIỂM CHỨNG (Design & Verification) một CNN accelerator INT8
  trên FPGA cho phân loại ECG. Trọng tâm = PHẦN CỨNG, không phải model CNN mới.
- Venue thật = ICDV (không phải MDPI — kế hoạch MDPI cũ trong Proposal đã lỗi thời).
- Điểm nhấn: bit-exact verification + DSE 2 dataflow (8-PE vs SIMD-20) + power-of-2 0-DSP.
- KHÔNG bán: accuracy SoTA (model nhỏ không thắng model lớn), novelty kiến trúc HW
  (8-PE time-multiplexed là chuẩn), novelty AF detection (đã bão hòa).
- BÁN: footprint cực nhỏ (ALM 5% vs Liu 51%), bit-exact, power-of-2 0-DSP rescale,
  tính tổng quát của kiến trúc (1 bitstream nhiều bài toán ECG 10s).

[x] Xác nhận Chapman ĐỦ uy tín: grouping 11->4 do CARDIOLOGIST đề xuất (Zheng 2020,

    cùng grouping. => KHÔNG cần đổi dataset; phản biện "nhãn không đáng tin" là hiểu lầm.

[x] Probe MIT-BIH beat morphology (N,L,R,A,V) — kiểm chứng kiến trúc học morphology:
    - 4-4-8-8, window 256, pool 5/5/2/2, clean split (no leakage):
        acc 97.42% / macro-F1 0.9354 / A(APC)-F1 0.802
    - + FC hidden 8->16->5: TỆ HƠN (F1 0.9263, A 0.752) → hidden FC vô ích, nút thắt
      không ở FC. ĐỪNG thêm hidden FC.
    - Nới kênh 8-8-16-16 (window 256): acc 98.66% / F1 0.9619 / A 0.874 → capacity conv
      LÀ nút thắt (nới kênh cứu lớp A). Nhưng params 640->2413, mất "tiny".
    - 3-conv window 250 pool 5/5/5 (L=10 SIMD-friendly): (4,8,16) acc 98.07% / F1 0.9497
      / A 0.848 — TỐT, ít params (933), ánh xạ SIMD L=10 sạch. Nới (8,16,16) lại tệ hơn
      (overfit window ngắn).

[x] Phân tích SIMD lane (L) cho window khác Chapman:
    - L phải chia hết mọi out_len + bội mọi pool-stride.
    - 256/pool-5/5/2/2: KHÔNG có L sạch (stride trộn 5,2). Per-layer len: 256/51/10/5/2.
    - 250/pool-5/5/5 (3 conv): L=10 sạch (len 250/50/10).
    - 625/pool-5/5/5/5: L=5. → ĐỀ XUẤT nếu làm SIMD cho beat: L=10, window 250, 3 conv.

[x] Probe AF/non-AF (2 nhãn) — HƯỚNG MẠNH NHẤT, cùng input 2500 = KHÔNG đổi RTL:
    Tất cả model 4-4-8-8 FC 8->2, 622 params, oversample TRAIN balanced.
    ┌─────────────────────────┬──────────┬───────┬───────┬──────┬──────┐
    │ Setup                   │ %AF      │ AUC   │ MacF1 │ Sens │ Spec │
    ├─────────────────────────┼──────────┼───────┼───────┼──────┼──────┤
    │ AFDB intra-patient      │ ~40%     │  —    │ 0.984 │  —   │  —   │ (acc 98.48, LEAKY)
    │ AFDB INTER-patient 5fold│ 40.5%    │ 0.905 │ 0.820 │ 0.930│ 0.747│ (fold-2 collapse)
    │ AFDB -> PTB-XL zeroshot │ 7.2%     │ 0.951 │ 0.767 │ 0.820│ 0.923│

    - Dataset có nhãn AF: AFDB ~40%, Chapman 20.9% (AFIB+AF), PTB-XL 7.2% (AFIB+AFLT).

5. QUYẾT ĐỊNH METRIC CHO CROSS-DATASET (chốt 2026-06-23)
--------------------------------------------------------------------------------
Thứ tự ưu tiên (vì lệch lớp + lệch ngưỡng cross-dataset):
  1. AUC          — số CHÍNH (không phụ thuộc ngưỡng, bất biến prevalence).
  2. Sens + Spec  — CẶP bắt buộc (metric lâm sàng sàng lọc AF).
  3. Macro-F1     — kèm theo (nhạy ngưỡng, không dùng kết luận generalization).
  4. Accuracy     — gần như BỎ (lệch lớp → vô nghĩa; PTB-XL 7% AF, đoán toàn non-AF=93%).

6. HƯỚNG ĐÃ LOẠI (ablation âm — đã đo, ĐỪNG thử lại)
--------------------------------------------------------------------------------
[x] INT4: mất ~19% acc kể cả general-scale (trần 75.6%), AFIB sập. INT8 = sweet-spot.
[x] SNN conversion: naive ANN->SNN cap ~58% (maxpool+signed+feature-map nhỏ).
[x] Depthwise-separable: NO-GO ở model nhỏ; INT8 power-of-2 sập 3.6-9.5pp.
[x] Operand-gating idle PE: chỉ −1.2mW (<1%) trên Cyclone IV (MULT chỉ 8% dynamic).
[x] Ping-pong pack 512×16: giảm M10K nhưng fail timing Avalon I/O.
[x] HR fusion (cứu SB/SR): +13pp cross-dataset nhưng phá in-dist → không ship.
[x] FC hidden layer (8->16->5) cho beat: tệ hơn, nút thắt không ở FC.
[x] Trục B đo energy general vs power-of-2: bỏ (DSP-count estimate đủ cho C1).
